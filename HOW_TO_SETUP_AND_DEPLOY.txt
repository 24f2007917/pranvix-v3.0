  → Left sidebar → Build → Firestore Database

STEP 6 — Set Firestore Security Rules
  → Firestore → Rules tab → Replace ALL content with:

  rules_version = '2';
  service cloud.firestore {
    match /databases/{database}/documents {

      match /users/{userId} {
        allow read: if request.auth != null;
        allow write: if request.auth.uid == userId;
      }

      match /usernames/{username} {
        allow read, create: if request.auth != null;
      }

      match /chats/{userId}/sessions/{sessionId} {
        allow read, write: if request.auth.uid == userId;
      }

      match /chats/{userId}/sessions/{sessionId} {
        allow read: if request.auth.token.email == "ujjwalsingh16072006@bbdu.ac.in";
      }

      match /stats/{doc} {
        allow read, write: if request.auth != null;
      }

      match /uploads/{userId}/files/{fileId} {
        allow read, write: if request.auth.uid == userId;
        allow read: if request.auth.token.email == "ujjwalsingh16072006@bbdu.ac.in";
      }
    }
  }

  → Click "Publish"

STEP 7 — Enable Firebase Storage
  → Left sidebar → Build → Storage
  → Click "Get Started" → TEST MODE → Next → Done

STEP 8 — Set Storage Security Rules
  → Storage → Rules tab → Replace with:

  rules_version = '2';
  service firebase.storage {
    match /b/{bucket}/o {
      match /uploads/{userId}/{allPaths=**} {
        allow read: if request.auth != null;
        allow write: if request.auth.uid == userId
                     && request.resource.size < 10 * 1024 * 1024
                     && (request.resource.contentType.matches('image/.*')
                         || request.resource.contentType == 'application/pdf');
      }
    }
  }

  → Click "Publish"

  HOW FILE UPLOADS WORK (Technical Summary)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  User uploads IMAGE (JPG/PNG/WEBP):
  1. Browser reads it as base64
  2. File is uploaded to Firebase Storage (for display)
  3. base64 data is sent to /api/chat with imageMimeType
  4. Server detects imageBase64 is present → calls GEMINI API
  5. Gemini 1.5 Flash reads the image and replies
  6. Reply shown with "✨ Gemini" badge

  User uploads PDF:
  1. Browser loads PDF with PDF.js (runs locally, no server needed)
  2. Text is extracted from all pages (max 20 pages)
  3. File is uploaded to Firebase Storage (so user can re-download)
  4. Extracted text is added to the chat message
  5. Text message (with PDF content) is sent to Groq Llama 3
  6. Reply shown with "⚡ Groq" badge

     → Use your official college email to register

  ❌ Images not loading after upload
     → Check Firebase Storage rules are published correctly

  ❌ PDF extraction showing 0 pages
     → Make sure PDF is not password-protected / scanned image PDF
     → Scanned PDFs (image-only) have no extractable text

  ❌ Admin panel says "Access denied"
     → Make sure ADMIN_EMAIL in firebase-config.js matches exactly
